# SpringRP GitBook rules

- This repository is the public GitBook source: https://github.com/SpringRP/SpringRP-gitbook, branch `main`.
- Book pages live at the repository root. Update `SUMMARY.md` when adding, moving or removing pages.
- Preserve Markdown/GitBook formatting, relative links and media in `.gitbook/assets/`.
- Server and launcher source, releases and infrastructure instructions belong to https://github.com/SpringRP/SpringRP-base. Keep launcher download links pointing to that repository.
- Do not copy credentials or the private infrastructure runbook into this public repository.
