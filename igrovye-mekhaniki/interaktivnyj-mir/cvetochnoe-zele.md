# Цветочное зелье

На обычной зельеварке приготовь **мутное зелье**, затем добавь **факельник**. Нужен обычный запас огненного порошка для работы зельеварки.

Возьми готовое зелье и нажми **Shift + ПКМ по нюхачу**. Одна бутылка расходуется, пустая возвращается. Нюхач получает **+25% скорости на пять минут**; на его полоске здоровья меняется оформление и показывается оставшееся время.

Если выпить зелье самому, персонаж загорится на **3–5 секунд**. Для лечения нюхача нужны [обычные цветы](nyukhachi.md), а не это зелье.
