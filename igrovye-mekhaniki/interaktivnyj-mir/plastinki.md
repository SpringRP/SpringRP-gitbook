# Пластинки со своим звуком

Аддон **pv-addon-discs** позволяет записать пользовательскую аудиозапись на музыкальную пластинку. Для прослушивания нужен **Plasmo Voice**. Готовая пластинка используется в проигрывателе.

Создание и очистка по умолчанию доступны администраторам. Держи музыкальную пластинку в руке:

```text
/disc burn <ссылка> [название]
/disc erase
/disc search <запрос>
```

`burn` записывает звук по ссылке, `erase` возвращает обычную пластинку, `search` ищет запись на YouTube. Доступность источников зависит от серверной настройки загрузчика; не каждая ссылка обязана загружаться. После переноса на текущую серверную линию работа внешних источников требует отдельной проверки.

Права: `pv.addon.discs.burn`, `pv.addon.discs.erase`, `pv.addon.discs.search`; прослушивание — `pv.addon.discs.play`. Установкой занимается администрация: игроку отдельный клиентский аддон пластинок не требуется.
