# Плакаты

Настенные плакаты — не обычные картины. \
При обычном `ПКМ` они отлетают от стены, переворачиваются и покачиваются, затем возвращаются на место. Плакаты можно скрафтить и разместить на вертикальной грани любого твёрдого блока.&#x20;

### Как скрафтить

Для любого варианта используется одна схема:

```
Палка   Бумага   Палка
Бумага  Краситель Бумага
Пусто   Пусто    Пусто
```

Краситель в центре определяет внешний вид:

| Вариант           | Центральный ингредиент      |
| ----------------- | --------------------------- |
| Плакат 1          | Красный краситель           |
| Плакат 2          | Оранжевый краситель         |
| Плакат 3          | Жёлтый краситель            |
| Плакат 4          | Лаймовый краситель          |
| Плакат 5          | Голубой краситель           |
| Плакат 6          | Синий краситель             |
| Плакат 7          | Фиолетовый краситель        |
| Плакат 8          | Пурпурный краситель         |
| Плакат 9          | Чёрный краситель            |
| Плакат 10         | Чернильный мешок            |
| Старый плакат     | Коричневый краситель        |
| Бумажный плакат 1 | Белый краситель             |
| Бумажный плакат 2 | Серый краситель             |
| Свой плакат       | Светящийся чернильный мешок |

Рецепты доступны в книге рецептов после первого получения нужных ингредиентов.

### Установка и взаимодействие

1. Возьми скрафченный плакат в руку.
2. Нажми `ПКМ` по блоку для установки плаката.
3. Нажми `ПКМ` по плакату, чтобы открыть его анимацию.
4. Нажми `Shift+ПКМ`, чтобы открыть редактор. Редактор один для всех видов плакатов: обычных, старых, бумажных и «своих».

В редакторе можно добавить заголовок, основной текст, подпись, декор и до трёх голов игроков по нику. После сохранения содержимое видно всем игрокам с установленным актуальным клиентом SpringRP.

Свой плакат может сломать любой игрок. При разрушении возвращается предмет плаката, а сохранённый текст и декор удаляются вместе с ним.

Административные плакаты (поставленные персоналом) редактирует только администратор. Блок, на котором такой плакат висит, игроки не ломают — ни рукой, ни взрывом, ни поршнем.

Для просмотра текстуры, текста, голов и декора нужен актуальный ресурспак и клиентский мод `SpringRP Posters`. Лаунчер проверяет обязательные файлы автоматически.
