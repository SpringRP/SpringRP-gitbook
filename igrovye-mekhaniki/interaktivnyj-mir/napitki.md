## Чайная смесь

**Чайная смесь** (англ. _Tea Blend_) — сухой мешочек с ягодами. В описании предмета: «Используется для приготовления чая».

### Крафт

Бесформенный рецепт: ингредиенты можно класть в любом порядке на верстаке **2×2** или **3×3**.

| Ингредиент       | Что взять                          |
| ---------------- | ---------------------------------- |
| Мешочек          | Обычный или любой цветной `bundle` |
| Светящиеся ягоды | `glow_berries`                     |
| Сладкие ягоды    | `sweet_berries`                    |

На выходе — один предмет **Чайная смесь**. Цвет строки «Используется для приготовления чая» совпадает с цветом мешочка, который положили в крафт (обычный мешочек — коричневый).

## Напитки в котле

1. Поставь котёл с водой **прямо над зажжённым обычным костром**. Костёр душ не подходит.
2. Добавь ингредиенты нужного рецепта через **ПКМ по котлу**.
3. После полного набора ингредиентов подожди **15 секунд нагрева**. Если потушить или убрать костёр, приготовление приостанавливается.
4. Забери готовый напиток **ПКМ стеклянной бутылкой**. Каждая порция расходует один уровень воды.

| Напиток | Ингредиенты |
| --- | --- |
| Чай | Сахар + светящиеся ягоды |
| Кофе | Два какао-боба + сахар |
| Билк | Сахар + ведро молока + семена пшеницы |
| Светлое пиво | Семена пшеницы + пшеница |
| Пиво из светящихся ягод | Семена пшеницы + светящиеся ягоды |
| Хлебное пиво | Семена пшеницы + хлеб |
| Ягодное пиво | Семена пшеницы + сладкие ягоды |

Если количество не указано, нужен один предмет каждого вида. Сухая чайная смесь — отдельный крафт; в текущем рецепте котла используются сахар и светящиеся ягоды, а не мешочек.
