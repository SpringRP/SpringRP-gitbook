# Общение и управление

### Шлепки (скрытые никнеймы)

Ники над головами игроков скрыты. Имена в чате и списке Tab при этом остаются. Чтобы узнать имя человека, нажми по нему **ПКМ**:

* обычный `ПКМ` — персонаж хлопнет игрока по спине; игрок увидит шлепок.
* с вероятностью 10% получится более неловкий шлепок;  игрок увидит шлепок.
* `Shift + ПКМ` используется для взаимодействия предметами, например дубинкой и наручниками; отдельного знакомства этим жестом сейчас нет.

Имя появляется в строке над хотбаром. Балаклава скрывает личность. Обычный хлопок не должен затемнять экран.





### Голосовой чат

Plasmo Voice передаёт голос окружающим игрокам. Доступны три дистанции речи:

* шёпот — 8 блоков;
* обычный голос — 16 блоков;
* крик — 32 блока.

Дистанцию, микрофон и громкость других игроков можно менять в меню голосового чата.

### Эмоции

Emotecraft отвечает за дополнительные анимации персонажа. Открой колесо эмоций назначенной клавишей и выбери движение — его увидят другие игроки с совместимым клиентом.

### Позы игрока

* `[` — лечь или перейти в ползание;
* `]` — сесть;
* `Shift` — выйти из текущей позы;
* движение прерывает сидение;
* лёжа можно продолжать ползти.

Из сидения можно сразу перейти в лежание и наоборот. Для работы данных клавиш необходим мод Clientizen.

### Стук в дверь

`Shift + ЛКМ` по двери запускает три быстрых стука. Для деревянной двери используется звук установки досок, для железной — железного блока. Стук слышен поблизости, примерно в радиусе 20 блоков.

О других взаимодействиях — [дубинка и наручники](interaktivnyj-mir/dubinka-i-naruchniki.md). Во время нокаута выйти из принудительной позы обычным Shift нельзя.
