# Вылетающие платформы

SpringPlatforms позволяет сохранить готовую постройку и плавно поднимать её из пола, опускать обратно или запускать по цепочке. Клиентский мод игрокам не нужен.

Все команды выполняются администратором с правом `springplatform.admin` (по умолчанию оно есть у операторов).

## Быстрое создание

1. Постройте платформу **в том месте и виде, в котором она должна находиться после появления**.
2. Возьмите топор WorldEdit командой `//wand`.
3. Выделите всю постройку: ЛКМ — первый угол, ПКМ — второй.
4. Сохраните её:

```text
/splatform create plaza
```

Вместо `plaza` используйте короткое уникальное имя латиницей. После создания блоки исчезнут — это нормально: платформа сохранена и находится в скрытом состоянии.

5. Настройте движение:

```text
/splatform set plaza direction up
/splatform set plaza distance 4
/splatform set plaza duration 60
```

- `direction` — направление появления: `up`, `down`, `north`, `south`, `east` или `west`;
- `distance` — расстояние движения в блоках;
- `duration` — длительность анимации в тиках: 20 тиков равны 1 секунде.

Проверьте результат:

```text
/splatform open plaza
/splatform close plaza
```

## Как включать платформу

### Нажатие по блоку

Посмотрите на кнопку, рычаг или другой нужный блок и выполните:

```text
/splatform trigger plaza click
```

Теперь ПКМ по этому блоку переключает платформу.

### Сигнал редстоуна

Посмотрите на блок, который получает сигнал, и выполните:

```text
/splatform trigger plaza redstone
```

Для нажимной плиты используется:

```text
/splatform trigger plaza plate
```

### Вход игрока в область

Выделите область с помощью WorldEdit, затем выполните:

```text
/splatform trigger plaza region
```

Платформа включится, когда игрок войдёт в выделенную область.

### Таймер

Для автоматического включения каждые 30 секунд:

```text
/splatform trigger plaza timer 30
```

Отключить назначенный триггер:

```text
/splatform trigger plaza none
```

## Автоматическое закрытие и цепочки

Чтобы платформа закрывалась через 15 секунд после появления:

```text
/splatform set plaza active-time 15
/splatform set plaza reverse true
```

Чтобы после неё запустилась другая платформа:

```text
/splatform set plaza next second_platform
```

Убрать продолжение цепочки:

```text
/splatform set plaza next none
```

Защита блоков платформы включена по умолчанию. Управление защитой:

```text
/splatform set plaza protect true
/splatform set plaza protect false
```

## Управление и исправление ошибок

```text
/splatform list
/splatform info plaza
/splatform open plaza
/splatform close plaza
/splatform toggle plaza
/splatform reset plaza active
/splatform reset plaza hidden
/splatform reload
```

- `list` — показать все платформы;
- `info` — показать размер, состояние и триггер;
- `open`, `close`, `toggle` — ручное управление;
- `reset ... active` — мгновенно вернуть платформу в открытое состояние;
- `reset ... hidden` — мгновенно скрыть платформу;
- `reload` — перечитать настройки плагина.

Если анимация прервалась или визуальные блоки зависли, сначала используйте нужный вариант `reset`.

Удаление платформы:

```text
/splatform delete plaza
```

{% hint style="danger" %}
`delete` удаляет запись платформы и её сохранённую схему. Перед удалением при необходимости выполните `/splatform reset plaza active`, чтобы оставить реальные блоки в мире.
{% endhint %}

## Важные ограничения

- Во время движения платформа состоит из визуальных блоков и **не имеет коллизии**. Реальные блоки появляются после завершения анимации.
- Вход игрока в движущийся объём блокируется, но нельзя использовать такую платформу как лифт с игроком на ней.
- Не выделяйте вместе с платформой лишний воздух и далёкие блоки.
- Одна платформа может содержать до 8000 блоков. Для плавной анимации рекомендуется не превышать примерно 2500 видимых блоков.
- Платформу с включённой защитой нельзя ломать, сдвигать поршнями, разрушать взрывом, заливать жидкостью или изменять физикой мира. Администратор с правом `springplatform.bypass` обходит защиту.
- После обновления JAR нужен полный перезапуск Paper/Purpur. `/reload` и `/ex reload` новый плагин не загружают.

## Интеграция с Denizen

Для сценариев Denizen доступны события:

```text
springplatform_opening
springplatform_active
springplatform_closing
springplatform_hidden
```

В контексте события передаётся `id` платформы. Запустить платформу из Denizen можно консольной командой `splatform open <id>`.

## Экранный эффект при вылете

При открытии платформы игрокам того же мира в радиусе 50 блоков автоматически отправляется клиентский эффект `shake` на время анимации. Эффект работает только у клиентов с обновлённым SpringPoster; остальные игроки продолжают видеть обычную анимацию без отключения.

Параметры находятся в `plugins/SpringPlatforms/config.yml`:

```yaml
animation:
  screen-effect:
    enabled: true
    effect: shake
    radius: 50.0
    duration-padding-ticks: 3
```

`radius` ограничивается 0–128 блоками, а `duration-padding-ticks` добавляет запас к длительности движения. Для отключения установите `enabled: false` и выполните `/splatform reload`.
