# Проверка плакатов после обновления

Чек-лист для Minecraft Java **26.3**, актуализирован 21 октября 2026 года. Это сценарии проверки, а не утверждение, что каждый пункт уже пройден на основном сервере.

Проверяй через `play.springrp.ru`, с принятым ресурспаком и актуальной сборкой. Желательно два игрока с разными правами.

| Действие | Ожидаемый результат |
| --- | --- |
| Скрафтить, установить, открыть плакат ПКМ | Анимация не дублирует объект и возвращает его на стену |
| Shift + ПКМ владельцем, изменить текст | Открывается редактор; сохранённый текст виден обоим зрителям |
| Добавить длинный текст и головы | Текст остаётся в поле листа, головы движутся вместе с ним |
| Открыть два редактора одновременно | Конкурирующее изменение не затирает чужое молча |
| Попытка изменить чужой плакат обычным игроком | Соблюдаются права владельца |
| Выдать только `springrp.poster.edit.any` | Чужой игровой плакат доступен, административный — нет |
| Проверить `springrp.poster.admin` | Администратор может изменить оба вида |
| Ломание опоры административного плаката | Обычное ломание, поршень и взрыв не сносят опору |
| Выгрузить и загрузить чанк | Нет пропавших или двойных моделей |
| Перезапуск, выполненный владельцем сервера | Содержимое и положение сохраняются |
| `/springrp poster force` после зависшего просмотра | Сеанс закрыт, плакат на стене |
| Удалить один тестовый плакат | Остальные плакаты не затронуты |

## Готовые страницы

После активации обновления просмотра проверь `page_1` и `page_10`: открывается диалог **чтения**, рисунок целый, нет редактора текста. Закрытие кнопкой и Escape, повторное открытие и два зрителя должны работать независимо. Сравни клиент с модом и без него, затем проверь обычный редактируемый плакат.

Для отчёта достаточно: дата, тип плаката, действие, результат, скриншот и отрывок лога с временем ошибки. Активация этого обновления и его проверка отделены от уже подтверждённой владельцем работы кат-сцен.
