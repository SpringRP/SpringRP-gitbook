# Тестовый стенд сокровищ

Право: `springridablesniffer.admin`. Для проверки не нужно приручать нюхача или ждать его КД.

```text
/springrp ridablesniffer testloot
```

В GUI доступны темы, выбор редкости и вкладка **всех таблиц лута**. Открой нужную таблицу, чтобы посмотреть её содержимое и проверить выдачу.

## Сундук перед собой

```text
/springrp ridablesniffer spawnchest armory epic
```

Создаёт оружейный сундук эпической редкости перед администратором с анимацией появления. Над ним показываются тема и редкость. Для проверки коллизии открой сундук с нескольких сторон и сравни видимую модель с областью нажатия.

| Тема | ID |
| --- | --- |
| Обычный | `general` |
| Морской | `sea` |
| Книжный | `books` |
| Оружейный | `armory` |
| Сокровищница | `vault` |
| Варденовский | `warden` |
| Адский | `nether` |
| Эндовский | `end` |
| Винный | `wine` |

Редкости: `common`, `uncommon`, `rare`, `epic`, `legendary`. Всего 45 сочетаний. Правила прочности и чар — на странице [нюхачей](../igrovye-mekhaniki/interaktivnyj-mir/nyukhachi.md).

```text
/springrp ridablesniffer status
/springrp ridablesniffer reload
```

Таблицы находятся в `plugins/SpringRidableSniffer/config.yml`. После изменения перечитай конфигурацию и проверь через GUI. Не обещай игрокам предметы из старого списка предложений: актуальное содержимое определяется текущей конфигурацией.
