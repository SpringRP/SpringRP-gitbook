# Панели управления

Панель — анимированные кнопки на поверхности блока. Право настройки: `springrp.panel.admin`.

## Установка и текстура

Посмотри на твёрдый блок не дальше шести блоков и выполни:

```text
/springrp panel 2
/springrp panel 4
```

Выбери одну команду: `2` — две кнопки, `4` — четыре. Перед поверхностью нужно свободное место для панели.

Текстура выбирается **автоматически по блоку-опоре**. Поддерживаются камень, булыжник, глубинный сланец, дубовые, еловые и берёзовые доски, кирпичи и песчаник. Для остальных блоков используется камень. Передавать название текстуры третьим аргументом не нужно.

## Назначение действий

Смотри на установленную панель:

```text
/springrp panel info
/springrp panel bind left platform gate toggle
/springrp panel bind right cutscene intro
/springrp panel bind right sfx shake 3
```

`gate` — существующая платформа или дверь, `intro` — существующая сцена. У одной кнопки могут быть привязки разных типов; повторное назначение того же типа заменяет его значение.

| Панель | Идентификаторы кнопок |
| --- | --- |
| Две кнопки | `left`, `right` |
| Четыре кнопки | `leftandup`, `leftanddown`, `rightandup`, `rightanddown` |

| Тип | Значение | Дополнительный аргумент |
| --- | --- | --- |
| `cutscene` | ID сцены | Не нужен |
| `trigger` | ID пользовательского события Denizen | Не нужен |
| `sfx` | ID экранного эффекта | Длительность 1–300 секунд |
| `sound` | ID звука | Не нужен |
| `platform` | ID платформы или двери | `open`, `close` или `toggle` |

Пространственный VFX выбирается через отдельный диалог: наведи взгляд на лицевую сторону нужной кнопки и выполни `/springrp panel vfx`.

## Снять назначение или панель

```text
/springrp panel unbind left platform
/springrp panel unbind right all
/springrp panel remove
```

`unbind` очищает указанное действие или все действия кнопки; `remove` удаляет саму панель. Во всех случаях нужно смотреть на нужную панель в пределах шести блоков.

Тип `trigger` вызывает пользовательское событие Denizen с контекстом панели, кнопки и игрока. Это **не** запуск области SpringTriggers. Для областей используй отдельные команды плагина. Прямая привязка `cutscene` запускает сцену как ручной просмотр и не применяет историю одноразового входа области.
