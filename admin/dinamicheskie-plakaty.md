# Плакаты для администрации

Все редактируемые виды плакатов используют один редактор: обычный ПКМ запускает просмотр, **Shift + ПКМ** открывает редактирование при наличии прав. Актуальный клиент SpringRP отображает текст, головы и декор на анимированном листе. Серверный ресурспак тоже необходим.

## Владение и права

Игрок ставит собственный плакат через крафт или `create`. Административный `spawn` создаёт плакат для оформления мира.

| Право | Назначение |
| --- | --- |
| `springrp.poster.use` | Доступ к команде взаимодействия |
| `springrp.poster.create` | Создание своего плаката |
| `springrp.poster.edit`, `springrp.poster.edit.own` | Редактирование своего |
| `springrp.poster.edit.any` | Редактирование чужих **игровых** плакатов |
| `springrp.poster.delete.own`, `springrp.poster.delete.any` | Удаление по владению |
| `springrp.poster.break.admin` | Снос опоры административного плаката |
| `springrp.poster.admin` | Полное администрирование |

Одного `edit.any` недостаточно для административного плаката. Опора административного плаката защищена от обычного сноса, взрывов и поршней.

## Команды

Выполняй команды, глядя на нужный объект:

| Команда | Действие |
| --- | --- |
| `/springrp poster create` | Поставить собственный плакат на вертикальную грань |
| `/springrp poster spawn <тип>` | Поставить административный плакат |
| `/springrp poster edit` | Открыть редактор |
| `/springrp poster clone` | Выбрать источник, затем повторить на цели |
| `/springrp poster owner <ник>` | Изменить владельца |
| `/springrp poster info` | Сведения о целевом плакате |
| `/springrp poster list` | Список плакатов |
| `/springrp poster rerender` | Пересоздать предпросмотр |
| `/springrp poster admin unlock` | Снять блокировку редактирования |
| `/springrp poster force` | Завершить зависшие сеансы и вернуть плакаты |
| `/springrp poster remove` | Удалить целевой плакат |

Сначала проверяй прицельное удаление. Вариант `remove all` затрагивает все плакаты.

## Проверка и неполадки

После сохранения проверь один и тот же плакат с двух клиентов. Если содержимое не сохраняется, запиши текст ошибки и повтори сохранение: сбой предпросмотра не должен молча подменять сохранённую версию.

Готовые страницы `page_1`–`page_10` — отдельные изображения для чтения, а не редактируемые объявления. Для них подготовлен ванильный диалог просмотра; его активацию после обновления плагина проверяйте отдельно.

Подробный [чек-лист плакатов](poster-acceptance.md). Файлы базы и внутренние настройки сервисов не относятся к материалам для игроков.
