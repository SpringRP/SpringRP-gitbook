# Доступ и вход на сервер

Для игры нужна активная проходка SpringAuth. Можно использовать Microsoft-аккаунт или вход по обычному нику через совместимый лаунчер. Сервер не просит пароль от Minecraft.

## Первый вход

1. Получи у администрации проходку и приватный одноразовый код.
2. Отправь приложению SpringAuth в Discord `/claim XXXX-XXXX-XXXX`. Проходка привяжется к твоему Discord.
3. Получи SpringRP Launcher у администрации либо подготовь совместимую [сборку](kak-nachat/klientskaya-sborka.md).
4. Запусти Minecraft Java **26.3** с точным написанием выданного ника и подключись к `play.springrp.ru`.
5. При входе по нику оставайся в комнате ожидания и нажми **Подтвердить вход** в личном сообщении SpringAuth. Подтверждённое соединение автоматически перейдёт на сервер.

Если вход выполняешь не ты, нажми **Отклонить вход**.

Рабочий Microsoft-аккаунт, проверенный SpringRP Launcher, позволяет входить без повторной кнопки Discord. `/claim` нужен в обоих режимах при первоначальной привязке или после её административного сброса.

## Повторное подключение

После подтверждения входа по нику действует доверенная сессия на 30 минут для того же аккаунта, Discord и IP. Переподключение не продлевает этот срок. При смене IP потребуется новое подтверждение.

## Если не пускает

| Сообщение или проблема | Что сделать |
| --- | --- |
| Нет активной проходки | Уточни у администрации выдачу и срок действия |
| Сначала выполните `/claim` | Получи и активируй код; кнопка входа его не заменяет |
| Нет сообщения бота | Разреши личные сообщения в Discord и переподключись |
| Вход с другим ником | Проверь написание и регистр ника в лаунчере |
| Кнопка не переводит на сервер | Не выходи из комнаты ожидания; подтверди самую новую попытку |
| Ошибка мода или несовместимая версия | Обнови сборку через лаунчер; не смешивай моды разных версий |

В Discord `/help` показывает справку SpringAuth. Сервер проекта: [Discord SpringRP](https://discord.gg/WJunbrzRB).

Версии лаунчера и файлы обновлений хранятся в [SpringRP-base Releases](https://github.com/SpringRP/SpringRP-base/releases). Репозиторий закрыт: ссылки работают только для участников с доступом, а остальным GitHub показывает 404. В этом случае получи актуальный файл у администрации.
