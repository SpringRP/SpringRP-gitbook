# Доступ и вход на сервер

Для игры нужна активная проходка SpringRP. Лицензионный Minecraft необязателен:
можно использовать официальный аккаунт или обычный ник и любой совместимый
лаунчер. Пароля от Minecraft сервер не спрашивает.

## Быстрый старт

1. Получи у администратора проходку и приватный код вида
   `XXXX-XXXX-XXXX`.
2. Один раз отправь в Discord команду `/claim XXXX-XXXX-XXXX`. После этого
   SpringAuth привяжет выданный Minecraft-ник к твоему Discord.
3. Установи [SpringRP Launcher v0.1.5](https://github.com/ne-utka/SpringRP/releases/download/v0.1.5/springrp-launcher.exe)
   или используй другой подходящий лаунчер.
4. Запусти игру строго с тем ником, на который выдана проходка, и подключись к
   `185.9.145.210:32073`.
5. Ты попадёшь в безопасную комнату ожидания — Limbo. На экране появится
   восьмисимвольный код.
6. Отправь в Discord `/code XXXXXXXX`. После подтверждения это же соединение
   автоматически перейдёт на основной сервер: перезаходить не нужно.

Каждое новое подключение подтверждается новым `/code`. Команда `/claim` нужна
только для первоначальной привязки или после административного сброса.

## Команды SpringAuth в Discord

- `/claim значение` — один раз привязывает выданную проходку к Discord;
- `/code значение` — подтверждает текущее подключение;
- `/help` — показывает краткую подсказку.

Бот можно добавить в личные сообщения (User Install) — команды работают и в ЛС с приложением.

Discord-сервер проекта: https://discord.gg/WJunbrzRB

## Если не пускает на сервер

**Нет активной проходки** — администратор ещё не выполнил
`/springauth grant` или срок проходки закончился.

**Discord просит сначала выполнить `/claim`** — возьми одноразовый код у
администратора. Код входа из Limbo не заменяет код первоначальной привязки.

**Код `/code` не принимается** — используй самый новый код, показанный для
текущего подключения, и отправляй его с уже привязанного Discord.

**Другой ник в лаунчере** — используй тот же ник, что привязан к Discord.

**После подтверждения не переводит на сервер** — не отключайся из Limbo и
проверь, что вводишь код до истечения его срока.

## Как устроен вход по нику

Лаунчер **не** связывается с Discord и **не** хранит пароли. Он:

1. Лаунчер сохраняет выбранный ник локально в защищённой Windows-сессии.
2. Игра подключается к Velocity в `offline-mode`.
3. Velocity не доверяет UUID лаунчера: SpringAuth получает из Access API
   постоянный внутренний UUID выданной проходки.
4. Привязка и подтверждение происходят на серверной стороне через Discord.
