# Как начать

## 1. Получи доступ

Получи проходку у администрации и один раз привяжи её к Discord командой `/claim XXXX-XXXX-XXXX`. Код выдают приватно. Подробности — на странице [доступа](../dostup-i-launcher.md).

## 2. Установи игру

Получи у администрации **SpringRP Launcher для Windows**. Если у тебя есть доступ к репозиторию проекта, файл также доступен в [релизах SpringRP-base](https://github.com/SpringRP/SpringRP-base/releases). Репозиторий закрыт: без доступа GitHub показывает 404. Лаунчер подготавливает нужную версию игры и клиентские файлы проекта.

При использовании другого лаунчера нужны **Minecraft: Java Edition 26.3**, **Java 25** и актуальная [клиентская сборка](klientskaya-sborka.md). Текущая линия использует Fabric Loader **0.19.5**. Моды от прежних версий нельзя просто переносить в новую сборку.

## 3. Подключись

Добавь в сетевой игре сервер:

```text
play.springrp.ru
```

Используй точное написание ника, на который выдана проходка. При запросе сервера разреши загрузку ресурспака.

При входе по нику дождись сообщения SpringAuth в Discord и нажми **Подтвердить вход**. Рабочий Microsoft-аккаунт, проверенный SpringRP Launcher, позволяет войти без повторной кнопки; проходка и первоначальная привязка всё равно нужны.

## 4. Настрой управление

Проверь микрофон в Plasmo Voice и назначение клавиш эмоций. Позы: `[` — лечь/ползти, `]` — сесть, `Shift` — встать. Подробнее — [общение и управление](../../igrovye-mekhaniki/obshchenie.md).
