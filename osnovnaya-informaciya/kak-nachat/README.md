# Как начать

## 0. Получи доступ

На сервер пускает только с ролью **«игрок»**. Её выдаёт Discord-бот SpringAuth **на сервере**:

1. Зайди через [лаунчер SpringRP](../dostup-i-launcher.md) (Microsoft или ник).
2. На экране появится код — отправь **`/code 123456`** боту SpringAuth в Discord.

Подробно: [«Доступ и лаунчер»](../dostup-i-launcher.md).

## С нашего лаунчера

Скачайте [SpringRP Launcher v0.1.5](https://github.com/ne-utka/SpringRP/releases/download/v0.1.5/springrp-launcher.exe) и запустите игру — лаунчер автоматически установит всё необходимое и войдёт на сервер.

## С других лаунчеров

### 1. Подготовь игру

Запусти **Minecraft: Java Edition 26.1.2.**

При игре **с других лаунчеров** для полной поддержки механик [рекомендуется готовая клиентская сборка (Fabric).](https://modrinth.com/share/JIF5gj8t)

## <sup>2. Добавь сервер</sup>

В меню «Сетевая игра» добавь сервер с адресом:

```
5.129.240.121:25567
```

### 3. Прими ресurспack

При первом входе Minecraft предложит загрузить серверный ресurспак. Его нужно принять: без него уникальные предметы, плакаты и диктофоны будут выглядеть неправильно.

Если загрузка зависла:

1. Закрой игру.
2. Удали старую папку серверного ресurспака из `.minecraft/downloads`.
3. Запусти игру и подключись снова.

### 4. Проверь управление

После входа открой «Настройки → Управление» и назначь удобные кнопки для **Plasmo Voice** и **Emotecraft**. Клавиши поз сервера уже заданы: `[` — лечь, `]` — сесть.

Подробнее о модах и дополнительных визуальных настройках — на странице [«Клиентская сборка»](klientskaya-sborka.md).
